# BD - Bases de Dados
* Para o projecto, se querem uma nota boa tentem evitar temas muito complicados. A probabilidade de terem uma nota alta com um tema simples mas bem implementado é mais alta do que com um tema complexo com alguns erros (que resultam da sua complexidade). Ou seja, é preferível que escolham algo simples e depois vão adicionando complexidades, do que escolherem logo algo muito complicado à partida. Por exemplo, um tema muito complicado seria fazer a base de dados de um hospital. Um tema mais simples, em que podem adicionar complexidade, é, por exemplo, a base de dados de uma livraria. 
* Embora no ínicio o projecto possa parecer simples (e o tema complexo possa não trazer muitos problemas), à medida que o vão implementado pode começar a trazer alguns problemas, dado que o projecto vai complicando ao longo do semestre.
