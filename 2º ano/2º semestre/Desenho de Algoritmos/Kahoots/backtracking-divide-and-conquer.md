# Kahoot 2 - Backtracking and Divide-&-Conquer

1. Backtracking algorithms are implemented by constructing a tree of choices called as:
    > * Backtracking tree
    > * Node tree
    > * State-chart tree
    > * **State-space tree :heavy_check_mark:**
    
2. When a node has a possibility of reaching a complete solution, in backtracking it is said to be:
    > * Applicable
    > * Succeeding
    > * **Promising :heavy_check_mark:**
    > * Preceding

3. In backtracking, a pruned state-space tree is a sub-tree consisting of
    > * **visited (explored) nodes :heavy_check_mark:** 
    > * non-promising nodes
    > * a limited number of levels defined a priori
    > * solution nodes

4. The divide-&-conquer approach applies to problems in which:
    > * Subproblems should run in linear time
    > * **Subproblems are disjoint instances of the problem :heavy_check_mark:**
    > * Subproblems are instances of different problems
    > * Subproblems should be twice the problem size

5. The three main phases in the divide-&-conquer approach, in order, are:
    > * Divide, combine, and conquer
    > * Conquer, divide, and combine
    > * **Divide, conquer, and combine :heavy_check_mark:**
    > * Combine, divide, and conquer

6. The time complexity of the divide-&-conquer implementation of Merge Sort is:
    > * **O(n * log n) in all the 3 cases (worst, average and best) :heavy_check_mark:**
    > * O(n) in the best case
    > * O(n^2) in the worst case
    > * O(n * log n) in the best case only
