# ME - Métodos Estatísticos
* Em termos de pré-requisitos, dá jeito se tiverem percebido bem probabilidades no secundário, mas se não perceberam, também vão aprender. 
* Acompanhem sempre a matéria, pois todas as semanas têm de fazer uma ficha. Só as 4 melhores notas nessas fichas contam, no entanto, no exame sai tudo.
* O projeto serve para estarem em contato com regressão linear e para o exame só sai uma pergunta sobre isso. 
* Para as fichas têm alguns exemplos de anos anteriores, mas se fizerem os exercícios recomendados pelo professor safam-se e conseguem ter uma nota muito boa. 
* Para o exame, façam exames de anos anteriores.
