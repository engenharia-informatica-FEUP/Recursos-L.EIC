# RC - Redes de Computadores
* A cadeira está divida em duas partes: a parte prática e a parte teórica. De alguma forma, estas duas partes são independentes entre si e envolvem o seu próprio estudo. 
* A parte teórica é a matéria dada nas aulas teóricas que sairá nos exames. A matéria é extensa, com muitos pormenores e detalhes. Portanto, recomenda-se que não deixem esta parte para a última. Para além disso, no primeiro trabalho laboratorial a parte teórica pode não ser muito relevante, mas no segundo trabalho laboratorial já será, aquando o desenvolvimento do relatório. 
* A parte prática são dois trabalhos laboratoriais. Para os dois trabalhos laboratoriais precisam de já saber programar em C (trabalhar com ficheiros, implementar uma máquina de estados, ...). Tudo o resto, aprenderão com a cadeira. 
* Para a parte teórica, os slides são uma boa base para o estudo. Contudo, recomenda-se que leiam também o livro "Computer Networks", de Tanenbaum (ignorando as partes que não são abordadas nas aulas). 
* Para o segundo trabalho laboratorial, a parte sobre sockets, podem estudar através [deste](Beej’s%20Guide%20to%20Network%20Programming.pdf) livro ou [o capítulo 8 deste](O%20Sistema%20Operativo%20Unix.pdf).
