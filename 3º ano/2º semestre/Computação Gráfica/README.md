# CG - Computação Gráfica
* As aulas teóricas servem essencialmente para dar matéria que sairá no exame e que se relaciona, em parte, com o projecto.
* O melhor livro para estudar é "Introdução à Computação Gráfica", de João M. Pereira, João Brisson, António Coelho, Alfredo Ferreira, Mário Rui Gomes. Infelizmente, ainda não foi encontrado este livro online, portanto têm de o comprar ou requisitar da biblioteca. 
* Para estudar para o exame, a melhor estratégia é fazer exames de anos passsados, para além de saber bem a matéria.
